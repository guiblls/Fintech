# FinControl

Dashboard financeiro desenvolvido para a disciplina Front-End da FIAP.

## Funcionalidades

* Controle financeiro
* Saldo total
* Receitas
* Despesas
* Saldo líquido
* Últimas transações
* Contas a pagar
* Vencimentos próximos
* Gastos por categoria
* Dashboard responsivo

## Tecnologias

* HTML5
* CSS3
* Tailwind CSS
