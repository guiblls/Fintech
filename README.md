# FinControl:
Dashboard financeiro desenvolvido para a disciplina Front-End da FIAP.

## Funcionalidades:
* Controle financeiro
* Saldo total
* Receitas
* Despesas
* Saldo líquido
* Últimas transações
* Contas a pagar
* Vencimentos próximos
* Gastos por categoria
* Dashboard responsivo

Esse foi um trabalho criado para a nossa Fintech no Faculdade de ADS na Fiap, para acessa o Web, segue o link abaixo:
